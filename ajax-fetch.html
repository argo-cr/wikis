Solicitudes asíncronas con AJAX y Fetch

Aprenda a consumir una API, procesar respuestas JSON y controlar los estados antes, durante y después de una solicitud.

Contenido Conceptos Estructura HTML AJAX con jQuery Fetch Async / await Comparación Demostración

¿Qué es una solicitud asíncrona?

Permite enviar o recibir datos desde un servidor sin recargar completamente la página.

$.ajax()
AJAX de jQuery

Ofrece funciones específicas para preparar la solicitud y manejar el éxito, el error y la finalización.

fetch()
Fetch API

Es una herramienta nativa del navegador basada en promesas. No requiere instalar jQuery.

API utilizada: Rick and Morty API. Devuelve personajes e información relacionada en formato JSON.

Estructura HTML

Los resultados se insertarán dinámicamente dentro de #personajes y los mensajes se mostrarán en #mensaje.

<button id="btn-cargar">Cargar personajes</button>

<div id="mensaje"></div>
<div id="personajes"></div>

AJAX con jQuery

Primero se debe cargar jQuery. El archivo personalizado siempre se coloca después.

<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
<script src="js/scripts.js"></script>

Ejemplo básico

$.ajax({
  url: 'https://rickandmortyapi.com/api/character/',
  method: 'GET',
  dataType: 'json',

  beforeSend: function () {
    $('#mensaje').text('Cargando personajes...');
    $('#btn-cargar').prop('disabled', true);
  },

  success: function (response) {
    $('#mensaje').text('Consulta exitosa');

    response.results.forEach(function (personaje) {
      $('#personajes').append(`
        <article>
          <img src="${personaje.image}" alt="${personaje.name}">
          <h3>${personaje.name}</h3>
        </article>
      `);
    });
  },

  error: function (xhr, status, error) {
    $('#mensaje').text('No fue posible cargar los datos');
    console.error(xhr.status, status, error);
  },

  complete: function () {
    $('#btn-cargar').prop('disabled', false);
    console.log('La solicitud finalizó');
  }
});
Función¿Cuándo se ejecuta?
beforeSendAntes de enviar la solicitud.
successCuando se recibe una respuesta exitosa.
errorCuando ocurre un error.
completeAl finalizar, exista o no un error.

Fetch

Fetch no tiene una propiedad beforeSend. El código previo se coloca inmediatamente antes de ejecutar fetch().

// Antes de la solicitud
mensaje.textContent = 'Cargando personajes...';
boton.disabled = true;

fetch('https://rickandmortyapi.com/api/character/')
  .then(function (response) {
    if (!response.ok) {
      throw new Error(`Error HTTP: ${response.status}`);
    }

    return response.json();
  })
  .then(function (data) {
    // Solicitud exitosa
    mensaje.textContent = 'Consulta exitosa';

    data.results.forEach(function (personaje) {
      personajes.insertAdjacentHTML('beforeend', `
        <article>
          <img src="${personaje.image}" alt="${personaje.name}">
          <h3>${personaje.name}</h3>
        </article>
      `);
    });
  })
  .catch(function (error) {
    // Error
    mensaje.textContent = 'No fue posible cargar los datos';
    console.error(error);
  })
  .finally(function () {
    // Finalización
    boton.disabled = false;
    console.log('La solicitud finalizó');
  });
Importante: Fetch no trata automáticamente una respuesta HTTP 404 o 500 como un rechazo. Por eso se debe comprobar response.ok y lanzar el error mediante throw.

Fetch con async y await

Es otra forma de escribir la misma solicitud. try, catch y finally separan claramente cada etapa.

async function cargarPersonajes() {
  try {
    // Antes de la solicitud
    mensaje.textContent = 'Cargando...';
    boton.disabled = true;

    const response = await fetch(
      'https://rickandmortyapi.com/api/character/'
    );

    if (!response.ok) {
      throw new Error(`Error HTTP: ${response.status}`);
    }

    const data = await response.json();

    // Solicitud exitosa
    console.log(data.results);
    mensaje.textContent = 'Consulta exitosa';

  } catch (error) {
    // Error
    mensaje.textContent = 'Ocurrió un error';
    console.error(error);

  } finally {
    // Finalización
    boton.disabled = false;
  }
}
