01 · Fundamento

Una matriz es una tabla de datos

En Java, una matriz es un arreglo de arreglos. Cada dato se localiza usando dos índices: primero la fila y después la columna.

Fila

Recorrido horizontal. El primer índice indica en cuál fila está el dato.

Columna

Recorrido vertical. El segundo índice indica en cuál columna está el dato.

Índices desde cero

Una matriz 3×3 utiliza índices del 0 al 2, no del 1 al 3.

Cantidad total

Una matriz rectangular de 3×3 contiene 9 posiciones: filas × columnas.

Explora las coordenadas

Selecciona una celda. Observa cómo Java identifica primero la fila y luego la columna.

Celda seleccionada matriz[0][0] = 1

Fila 1 y columna 1 para una persona; índices 0 y 0 para Java.

!
Orden que no debes invertir

Lee matriz[i][j] como matriz[fila][columna]. En los ejemplos de esta guía, i representa la fila y j la columna.

02 · Estructura

Crear una matriz

Puedes escribir los valores directamente o decidir las dimensiones durante la ejecución. Una vez creada, la cantidad de posiciones no cambia.

Inicialización estática

Los valores ya se conocen cuando se escribe el programa.

  • Ideal para probar la lógica
  • Permite resultados predecibles
  • Útil en los ejercicios 1 y 7
VS

Dimensiones en ejecución

El usuario indica el tamaño antes de crear la matriz.

  • Las dimensiones pueden variar
  • El tamaño queda fijo después de crearla
  • Útil en los ejercicios 8, 9 y 14

Valores escritos directamente

Java · matriz 3×3 
int[][] matriz = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

System.out.println(matriz[1][2]); // Imprime 6

Dimensiones definidas durante la ejecución

Java · tamaño solicitado 
Scanner teclado = new Scanner(System.in);

System.out.print("Cantidad de filas: ");
int filas = teclado.nextInt();

System.out.print("Cantidad de columnas: ");
int columnas = teclado.nextInt();

int[][] matriz = new int[filas][columnas];
i
¿Qué significa “dinámica” aquí?

Significa que el tamaño o los valores se determinan mientras el programa se ejecuta. No significa que la matriz pueda agrandarse después: los arreglos de Java tienen tamaño fijo.

Las propiedades que siempre necesitarás

Expresión Significado Ejemplo en una matriz 3×4
matriz.length Cantidad de filas. 3
matriz[i].length Cantidad de columnas de la fila actual. 4
matriz.length - 1 Índice de la última fila. 2
matriz[0].length - 1 Índice de la última columna. 3
03 · Recorrido

Dos dimensiones, dos ciclos

El ciclo exterior controla las filas. Por cada fila, el ciclo interior visita todas sus columnas.

Java · recorrido universal 
for (int i = 0; i < matriz.length; i++) {
    for (int j = 0; j < matriz[i].length; j++) {
        // Trabajar con la posición actual
        System.out.print(matriz[i][j] + " ");
    }
    System.out.println(); // Cambiar de línea al terminar la fila
}

1. Entrar a una fila

El valor de i permanece fijo mientras se recorren sus columnas.

2. Visitar columnas

j cambia desde 0 hasta la última columna de esa fila.

3. Repetir

Al terminar una fila, i avanza y j vuelve a 0.

Mostrar una matriz ordenada

Java · método reutilizable 
static void mostrarMatriz(int[][] matriz) {
    for (int i = 0; i < matriz.length; i++) {
        for (int j = 0; j < matriz[i].length; j++) {
            System.out.printf("%5d", matriz[i][j]);
        }
        System.out.println();
    }
}
✓
Regla práctica

Usa siempre matriz.length y matriz[i].length como límites. Evita escribir números fijos como i < 3 si tu código debe funcionar con otros tamaños.

04 · Entrada

Llenar valores

La estructura de recorrido no cambia. Solo cambia de dónde proviene el valor que se asigna a cada celda.

Valores ingresados por el usuario

Java · Scanner 
for (int i = 0; i < matriz.length; i++) {
    for (int j = 0; j < matriz[i].length; j++) {
        System.out.printf("Valor de la fila %d, columna %d: ", i + 1, j + 1);
        matriz[i][j] = teclado.nextInt();
    }
}

El mensaje muestra i + 1 y j + 1 para hablarle al usuario desde 1, aunque internamente Java siga usando índices desde 0.

Valores aleatorios

Java · Random 
import java.util.Random;

Random random = new Random();

for (int i = 0; i < matriz.length; i++) {
    for (int j = 0; j < matriz[i].length; j++) {
        matriz[i][j] = random.nextInt(13); // Valores entre 0 y 12
    }
}

Fórmula para cualquier rango inclusivo

Para generar valores desde mínimo hasta máximo, incluyendo ambos extremos:

Java · rango 
int valor = random.nextInt(maximo - minimo + 1) + minimo;
!
Lee con cuidado el límite

random.nextInt(13) produce 0, 1, 2, …, 12. El número 13 funciona como límite superior y no puede aparecer.

05 · Procesamiento

Cálculos frecuentes

La mayoría de los ejercicios se resuelve recorriendo todas las celdas y actualizando acumuladores, contadores o valores de referencia.

Suma, promedio y conteos

Java · patrón de acumulación 
int suma = 0;
int cantidad = 0;
int pares = 0;
int multiplosDeTres = 0;

for (int i = 0; i < matriz.length; i++) {
    for (int j = 0; j < matriz[i].length; j++) {
        int valor = matriz[i][j];

        suma += valor;
        cantidad++;

        if (valor % 2 == 0) {
            pares++;
        }

        if (valor % 3 == 0) {
            multiplosDeTres++;
        }
    }
}

double promedio = (double) suma / cantidad;

Acumulador

Guarda un total progresivo. Ejemplo: suma += valor.

Contador

Aumenta cuando se cumple una condición. Ejemplo: pares++.

Conversión a double

Evita que Java elimine los decimales al dividir dos valores enteros.

Mayor y menor con su posición

Java · máximos y mínimos 
int mayor = matriz[0][0];
int menor = matriz[0][0];
int filaMayor = 0;
int columnaMayor = 0;

for (int i = 0; i < matriz.length; i++) {
    for (int j = 0; j < matriz[i].length; j++) {
        if (matriz[i][j] > mayor) {
            mayor = matriz[i][j];
            filaMayor = i;
            columnaMayor = j;
        }

        if (matriz[i][j] < menor) {
            menor = matriz[i][j];
        }
    }
}
×
No inicies siempre el mayor o el menor en cero

Si todos los datos fueran negativos, cero no sería un valor real de la matriz. Es más seguro comenzar con matriz[0][0].

Filas pares: primero define qué significa “par”

Interpretación Condición Filas incluidas en una matriz 5×5
Índice par de Java i % 2 == 0 Índices 0, 2 y 4
Número de fila par para una persona (i + 1) % 2 == 0 Filas 2 y 4; índices 1 y 3

Las cuatro esquinas

Java · funciona con cualquier matriz rectangular 
int ultimaFila = matriz.length - 1;
int ultimaColumna = matriz[0].length - 1;

double promedioEsquinas = (
        matriz[0][0] +
        matriz[0][ultimaColumna] +
        matriz[ultimaFila][0] +
        matriz[ultimaFila][ultimaColumna]
    ) / 4.0;
Patrón de apoyo para calcular la moda

Sin utilizar colecciones, puedes tomar cada valor como candidato y volver a recorrer la matriz para contar cuántas veces aparece. Si hay empate, este patrón conserva el primero encontrado.

Java · frecuencia por comparación 
int moda = matriz[0][0];
int frecuenciaModa = 0;

for (int i = 0; i < matriz.length; i++) {
    for (int j = 0; j < matriz[i].length; j++) {
        int candidato = matriz[i][j];
        int frecuencia = 0;

        for (int f = 0; f < matriz.length; f++) {
            for (int c = 0; c < matriz[f].length; c++) {
                if (matriz[f][c] == candidato) {
                    frecuencia++;
                }
            }
        }

        if (frecuencia > frecuenciaModa) {
            frecuenciaModa = frecuencia;
            moda = candidato;
        }
    }
}
06 · Tipos de datos

No todas las matrices son de enteros

La estructura es la misma para double, float, boolean, char y String. Solo cambia el tipo y las operaciones válidas.

Tipo Declaración Valor inicial automático Uso frecuente
int int[][] datos 0 Cantidades, identificadores, temperaturas enteras.
float float[][] datos 0.0 Valores con decimales.
boolean boolean[][] datos false Estados o resultados de una condición.
String String[][] datos null Palabras, nombres o descripciones.
char char[][] datos Carácter vacío Letras, tableros y dibujos.

Guardar el resultado de una condición

Java · String hacia boolean 
boolean[][] palabrasLargas = new boolean[2][2];

for (int i = 0; i < palabrasLargas.length; i++) {
    for (int j = 0; j < palabrasLargas[i].length; j++) {
        System.out.print("Digite una palabra: ");
        String palabra = teclado.nextLine();

        palabrasLargas[i][j] = palabra.length() > 9;
    }
}
!
length no siempre se escribe igual

En un arreglo se usa matriz.length, sin paréntesis. En un texto se usa palabra.length(), con paréntesis.

¿Por qué nextLine() a veces parece saltarse una lectura?

Después de nextInt(), queda pendiente el salto de línea que produjo Enter. Consúmelo una vez antes de comenzar a leer textos:

Java · limpiar el salto de línea 
int cantidad = teclado.nextInt();
teclado.nextLine(); // Consumir el Enter pendiente

System.out.print("Digite una palabra: ");
String palabra = teclado.nextLine();
07 · Coordenadas

Dibujar con una matriz 5×5

Para formar una figura, decide qué condición cumplen las celdas que deben mostrar un símbolo. Las demás guardan un espacio.

Ejemplo distinto a las letras asignadas

La figura “+” se construye encendiendo la fila central o la columna central. El mismo razonamiento sirve para diseñar cada letra sin memorizar dibujos.

Java · ejemplo de razonamiento 
char[][] lienzo = new char[5][5];

for (int i = 0; i < lienzo.length; i++) {
    for (int j = 0; j < lienzo[i].length; j++) {
        if (i == 2 || j == 2) {
            lienzo[i][j] = '*';
        } else {
            lienzo[i][j] = ' ';
        }
    }
}

Condiciones visuales útiles

Zona Condición general Qué representa
Primera fila i == 0 Línea horizontal superior.
Última fila i == matriz.length - 1 Línea horizontal inferior.
Primera columna j == 0 Línea vertical izquierda.
Última columna j == matriz[i].length - 1 Línea vertical derecha.
Diagonal principal i == j De arriba izquierda hacia abajo derecha.
Diagonal secundaria i + j == tamaño - 1 De arriba derecha hacia abajo izquierda.
✓
Primero dibuja en papel

Numera filas y columnas del 0 al 4, marca las celdas de la letra y busca qué tienen en común. Esa observación se convierte en condiciones con i y j.

08 · Aplicación

Tres modelos que requieren más análisis

Los últimos ejercicios no introducen una matriz nueva: combinan los mismos recorridos con una forma particular de interpretar filas y columnas.

Productos: filas como registros

Cada fila representa un producto y cada columna representa un dato del producto.

Java · estructura tabular 
final int COLUMNA_ID = 0;
final int COLUMNA_PRECIO = 1;
final int COLUMNA_CANTIDAD = 2;
final int COLUMNA_TOTAL = 3;

int[][] productos = new int[cantidadRegistros][4];

// Después de leer precio y cantidad de la fila i:
productos[i][COLUMNA_TOTAL] =
        productos[i][COLUMNA_PRECIO] * productos[i][COLUMNA_CANTIDAD];

Sumar dos matrices

La suma ocurre posición por posición. Ambas matrices deben tener exactamente las mismas dimensiones.

Java · misma coordenada 
int[][] resultado = new int[matrizA.length][matrizA[0].length];

for (int i = 0; i < matrizA.length; i++) {
    for (int j = 0; j < matrizA[i].length; j++) {
        resultado[i][j] = matrizA[i][j] + matrizB[i][j];
    }
}

Calendario: semanas y días

La fila representa la semana; la columna representa el día de la semana. Las posiciones que no pertenecen al mes deben usar un valor especial, por ejemplo -1, y excluirse de los cálculos.

!
Validación necesaria en el ejercicio 16

Una matriz 4×7 solo tiene 28 posiciones, por lo que no puede almacenar 30 días. Además, si el día 1 es miércoles, el día 30 cae jueves de una quinta semana. Antes de programar, utiliza la aclaración indicada por el docente; para representar el calendario completo se requiere una matriz 5×7.

Java · convertir posición lineal en fila y columna 
String[] dias = {"Lunes", "Martes", "Miércoles",
                 "Jueves", "Viernes", "Sábado", "Domingo"};

int inicio = 2; // Miércoles cuando lunes corresponde a 0
int posicion = inicio + diaDelMes - 1;
int semana = posicion / 7;
int diaSemana = posicion % 7;

Promedio semanal

Recorre solo la fila solicitada y divide entre la cantidad de días válidos, no siempre entre 7.

Día del máximo

Guarda la columna del valor mayor y úsala como índice en el arreglo dias.

Posiciones vacías

Comprueba valor != -1 antes de sumar, promediar o comparar.

09 · Depuración

Errores comunes y cómo reconocerlos

Leer el mensaje de error y revisar los límites suele ser suficiente para encontrar el problema.

ArrayIndexOutOfBoundsException

Se intentó acceder a una posición inexistente. Revisa si usaste <= matriz.length en lugar de < matriz.length.

Se repite o falta una celda

Verifica que el ciclo interior use j para controlar columnas y que la asignación sea matriz[i][j].

El promedio no tiene decimales

Al dividir enteros, Java produce división entera. Convierte la suma a double o divide entre un literal como 4.0.

nextLine() no espera texto

Hay un Enter pendiente después de nextInt(). Ejecuta un nextLine() adicional antes de leer la palabra.

Todo aparece en una sola línea

El System.out.println() que cambia de fila debe estar después del ciclo interior, pero dentro del exterior.

El máximo señala un día vacío

En estructuras como calendarios, descarta el valor especial de las posiciones que no pertenecen al mes.

El error de límite más frecuente

Incorrecto

i <= matriz.length

Intenta llegar hasta un índice igual a la cantidad de filas. Ese índice no existe.

→

Correcto

i < matriz.length

El último valor de i será matriz.length - 1.

10 · Herramienta

Flujo de trabajo en Eclipse

Avanza en fragmentos pequeños. Un programa que compila después de cada paso es mucho más fácil de corregir.

Crea un Java Project

Usa un nombre reconocible, por ejemplo EjerciciosMatrices.

Crea una clase para cada ejercicio

Agrega un requisito a la vez

Primero suma, ejecuta; luego promedio, ejecuta; después conteos, ejecuta.
