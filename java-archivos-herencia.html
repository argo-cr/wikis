¿Por qué ArrayList<Animal> acepta Mamifero y Reptil?

Java
ArrayList<Animal> lista = new ArrayList<>();
lista.add(new Mamifero(1, "Luna", "Gato", 4, "Casa"));
lista.add(new Reptil(2, "Cobra", "Serpiente", 3, true));

    System.out.println(a); // Ejecuta el toString() de su tipo real

Esto es polimorfismo: una variable de tipo Animal puede referirse a objetos de sus subclases. Java ejecuta el toString() que corresponda a cada objeto.

06 · Formato de animales.txt

Cada línea representa un objeto completo. Los valores se separan con punto y coma. El primer dato es el tipo de objeto, necesario para saber qué constructor utilizar al cargar.

REPTIL;2;Cobra;Serpiente;3;true

07 · Cargar: del archivo a los objetos

Este método lee animales.txt línea por línea, separa los datos, decide qué clase instanciar y agrega el objeto a la lista.

Java
public void cargar() {

		try {

			File f = new File(archivo);

			if (f.exists()) {

				Scanner lector = new Scanner(f);

				while (lector.hasNextLine()) {

					String linea = lector.nextLine();

					// DIVIDIR LA LÍNEA POR ;
					String partes[] = linea.split(";");

					// CREAR Y REGISTRAR EL OBJETO EN LA LISTA

					String TIPO = partes[0];

					int id = Integer.parseInt(partes[1]);
					String nombre = partes[2];
					String especie = partes[3];
					int peso = Integer.parseInt(partes[4]);

					Animal a = null;

					switch (TIPO) {
					case "MAMIFERO":
						String habitat = partes[5];
						a = new Mamifero(id, nombre, especie, peso, habitat);
						break;

					case "REPTIL":
						boolean venenoso = Boolean.parseBoolean(partes[5]);
						a = new Reptil(id, nombre, especie, peso, venenoso);
						break;

					default:
						a = new Animal(id, nombre, especie, peso);
						break;
					}

					// AGREGAMOS A LA LISTA
					lista.add(a);

					// SE TOMA EL ÚLTIMO ID REGISTRADO EN EL ARCHIVO
					// PARA CONTINUAR DESDE AHÍ
					this.id = id + 1;

				}

				lector.close();

			}

		} catch (Exception e) {
			e.printStackTrace();
		}

	}
1new File(archivo) representa la ruta del archivo.
2f.exists() verifica que exista.
3Scanner y hasNextLine() leen una línea por vez.
4split(";") divide el texto en un arreglo de cadenas.
5parseInt y parseBoolean convierten texto a números o booleanos.
6switch (TIPO) elige new Mamifero(...), new Reptil(...) o new Animal(...).
7lista.add(a) conserva el objeto en memoria.
Ejemplo concreto: al leer REPTIL;2;Cobra;Serpiente;3;true, el programa crea new Reptil(2, "Cobra", "Serpiente", 3, true). No crea primero un Animal y después un Reptil.

08 · Guardar: de los objetos al archivo

Este método realiza el proceso inverso: recorre el ArrayList, identifica el tipo real de cada objeto y escribe una línea completa en el archivo.

Java
public void guardar() {

		try {

			PrintWriter escritor = new PrintWriter(archivo);

			// SEGUIMOS EL FORMATO atributo1;atributo2;atributoN
			for (int i = 0; i < lista.size(); i++) {
				Animal a = lista.get(i);
				
				String linea = a.getId() + ";" + a.getNombre() + ";" + a.getEspecie() + ";" + a.getPeso();
				
				if(a instanceof Mamifero) {
					Mamifero m = (Mamifero) a;
					linea = "MAMIFERO" + ";" + linea + ";" + m.getHabitat();
				
				}else if(a instanceof Reptil) {
					Reptil r = (Reptil) a;
					linea = "REPTIL" + ";" + linea + ";" + r.isVenenoso();
				}else {
					linea = "ANIMAL" + ";" + linea;
				}
				
				escritor.println(linea);
			}

			escritor.close();

		} catch (Exception e) {
			e.printStackTrace();
		}

	}

¿Qué significa instanceof?

Java
Animal a = lista.get(i);

if (a instanceof Mamifero) {
    Mamifero m = (Mamifero) a;
    System.out.println(m.getHabitat());
}

instanceof pregunta si el objeto es un Mamifero. El casting (Mamifero) a permite acceder al método getHabitat(), que no existe en la clase padre.

¿Por qué se escribe el tipo al principio?

Al guardar se antepone MAMIFERO, REPTIL o ANIMAL. Gracias a esa palabra, cuando el programa se abre de nuevo, cargar() sabe qué subclase construir.

Importante: new PrintWriter(archivo) sobrescribe el archivo completo. Por eso primero se actualiza la lista en memoria y después se llama a guardar(). No se guardan objetos Java directamente: se guardan sus atributos como texto.

09 · CRUD sobre ArrayList

El proyecto implementa las operaciones en ListaAnimales. La lista es la fuente de datos mientras se ejecuta el programa; después de registrar, actualizar o eliminar, se vuelve a guardar el archivo.

Registrar

Java
public void registrar(Animal a) {
		a.setId(id++);
		lista.add(a);

		guardar();
	}

a.setId(id++) asigna el siguiente ID y aumenta el contador; lista.add(a) agrega el objeto; guardar() actualiza el archivo.

Buscar por ID

Java
public Animal buscar(int id) {

		Animal a = null;

		for (int i = 0; i < lista.size(); i++) {

			if (lista.get(i).getId() == id) {
				a = lista.get(i);
			}
		}

		return a;

	}

Recorre la lista y compara getId(). Si no encuentra coincidencia, devuelve null.

Eliminar

Java
public void eliminar(int id) {
		Animal encontrado = buscar(id);
		lista.remove(encontrado);

		guardar();
	}

Busca el objeto, lo elimina de la lista y guarda el resultado. Si no existe, remove(null) no elimina nada en este caso, aunque es más claro validar el resultado antes de guardar.

Actualizar: comportamiento del proyecto

Java
public void actualizar(Animal a, int id) {

		Animal encontrado = buscar(id);

		encontrado.setNombre(a.getNombre());
		encontrado.setEspecie(a.getEspecie());
		encontrado.setPeso(a.getPeso());

		guardar();
	}
Limitación del código original: este método actualiza solo nombre, especie y peso; no cambia habitat ni venenoso. Además, si no encuentra el ID, encontrado será null y producirá un error.

Alternativa sencilla para actualizar todo el objeto

Java
public void actualizar(Animal nuevo, int id) {
    for (int i = 0; i < lista.size(); i++) {
        if (lista.get(i).getId() == id) {
            nuevo.setId(id);
            lista.set(i, nuevo);
            guardar();
            return;
        }
    }
}

Con lista.set(i, nuevo) reemplazamos el objeto completo y conservamos su ID. Es útil cuando se quieren actualizar también los atributos de una subclase.

Ambos métodos recorren la misma lista. El filtro con instanceof selecciona solo los objetos del tipo solicitado. No se crean dos listas independientes.

Mostrar todos

Java
public String toString() {

		String data = "";

		for (int i = 0; i < lista.size(); i++) {
			Animal a = lista.get(i);
			data += a + "\n";
		}

		return data;
	}
Al concatenar data += a, Java utiliza automáticamente el método toString() del objeto real. Por eso un mamífero muestra su hábitat y un reptil muestra si es venenoso.

package app;

public class Controlador {

	private ListaAnimales animales;
	private Vista vista;

	public Controlador() {
		animales = new ListaAnimales();
		vista = new Vista();
	}

	public void iniciar() {

		int opcion = 0;

		do {
			
			vista.mostrarTitulo("Gestión de Animales");
			vista.mostrarMenuPrincipal();
			
			opcion = vista.pedirOpcion();
			
			switch (opcion) {
			case 1:
				registrarMamifero();
				break;
				
			case 2:
				registrarReptil();
				break;
				
			case 3:
				verMamiferos();
				break;
				
			case 4:
				verReptiles();
				break;
				
			case 5:
				verTodos();
				break;
				
			case 0:
				vista.mostrarMensaje("Saliendo...");
				break;

			default:
				vista.mostrarMensaje("Opción incorrecta");
				break;
			}
			

		} while (opcion != 0);

	}

	public void registrarMamifero() {
		vista.mostrarTitulo("REGISTRAR MAMÍFERO");
		Mamifero m = vista.crearMamifero();
		animales.registrar(m);
		vista.mostrarMensaje("Mamífero registrado...");
	}

	public void registrarReptil() {
		vista.mostrarTitulo("REGISTRAR REPTIL");
		Reptil r = vista.crearReptil();
		animales.registrar(r);
		vista.mostrarMensaje("Reptil registrado...");
	}

	public void verMamiferos() {
		vista.mostrarTitulo("VER MAMÍFEROS");
		String lista = animales.getMamiferos();
		vista.mostrarMensaje(lista);
	}

	public void verReptiles() {
		vista.mostrarTitulo("VER REPTILES");

		vista.mostrarTitulo("VER TODOS");

	}

Actividad 1 · Comprensión

Actividad 2 · ArrayList

Agrega tres animales. Muestra size(), recupera el segundo con get(1) y elimínalo por su ID usando buscar().

Actividad 3 · Persistencia

Preguntas de autoevaluación

¿Por qué no se necesita ListaMamiferos?

Porque ArrayList<Animal> acepta objetos de ambas subclases y podemos filtrarlos con instanceof.

¿Qué diferencia existe entre get(i) y getId()?

get(i) obtiene un objeto por su posición en el ArrayList; getId() devuelve el identificador propio de ese objeto.

¿Qué pasaría si no guardamos el tipo en animales.txt?

Al cargar no sabríamos si debemos construir un Animal, Mamifero o Reptil.

¿Qué pasa si modificamos la lista y no ejecutamos guardar()?

El cambio permanece solo en memoria y se pierde cuando termina el programa.
