01. Organización del proyecto

El ejemplo administra personas. La aplicación mantiene los objetos en un arreglo y utiliza el archivo para conservarlos entre ejecuciones.

Main

Punto de entrada del programa.

Persona

Representa los datos de cada persona.

ListaPersonas

Arreglo, operaciones CRUD y lectura/escritura del archivo.

Vista

Solicita datos y muestra mensajes en consola.

Controlador

Presenta el menú y coordina las operaciones.

Vista↔Controlador↔ListaPersonas↔personas.txt
El archivo no sustituye al arreglo: al iniciar se cargan los registros en memoria y, cuando se modifica la información, se guarda el contenido del arreglo.

02. ¿Cómo se almacena la información?

Cada línea representa una persona. Los atributos se separan mediante un punto y coma (;).

files/personas.txt 
1;Ana;21
2;Carlos;25
3;María;19
PosiciónDatoTipo Java
0IDint
1NombreString
2Edadint

Al leer 1;Ana;21, la instrucción split(";") produce tres partes: "1", "Ana" y "21". Los números llegan como texto y deben convertirse a int.

03. Modelo: Persona

La clase representa cada registro. El proyecto incluye dos constructores: uno para crear personas nuevas sin un ID asignado y otro para reconstruirlas desde el archivo con su ID original.

Persona.java · constructores 
public Persona(String nombre, int edad) {
    this.id = 0;
    this.nombre = nombre;
    this.edad = edad;
}

public Persona(int id, String nombre, int edad) {
    this.id = id;
    this.nombre = nombre;
    this.edad = edad;
}
Los métodos getId(), getNombre() y getEdad() permiten obtener los valores al construir las líneas del archivo.

04. Preparación de ListaPersonas

El constructor crea el arreglo, inicializa sus contadores, define la ruta del archivo y llama a cargar() para recuperar los datos existentes.

ListaPersonas.java · constructor 
private Persona lista[];
private int registros, id;
private String archivo;

public ListaPersonas() {
    lista = new Persona[100];
    registros = 0;
    id = 1;
    archivo = "files/personas.txt";
    cargar();
}

registros indica cuántas posiciones del arreglo están ocupadas; id guarda el siguiente identificador que se utilizará al registrar.

05. Leer el archivo: cargar()

Este método convierte las líneas del archivo en objetos Persona y los coloca en el arreglo.

ListaPersonas.java · cargar() 
public void cargar() {
    try {
        File f = new File(archivo);

        if (f.exists()) {
            Scanner lector = new Scanner(f);
            registros = 0;

            while (lector.hasNextLine()) {
                String linea = lector.nextLine();
                String partes[] = linea.split(";");

                int id = Integer.parseInt(partes[0]);
                String nombre = partes[1];
                int edad = Integer.parseInt(partes[2]);

                Persona p = new Persona(id, nombre, edad);
                lista[registros++] = p;
                this.id = id + 1;
            }
            lector.close();
        }
    } catch (Exception e) {
        e.printStackTrace();
    }
}

¿Qué hace cada instrucción?

InstrucciónFunción
new File(archivo)Representa la ruta del archivo.
f.exists()Comprueba que el archivo exista antes de leerlo.
new Scanner(f)Abre el archivo para lectura.
hasNextLine()Verifica si queda otra línea.
nextLine()Obtiene la línea completa.
split(";")Separa los atributos.
Integer.parseInt()Convierte texto en un entero.
lista[registros++] = pAlmacena el objeto y avanza el contador.
lector.close()Cierra el lector.
En el proyecto original, this.id = id + 1 toma como referencia el último ID leído. Por ello, este ejemplo presupone que las líneas están ordenadas por identificador.

06. Escribir el archivo: guardar()

Este método recorre los objetos que hay en memoria, transforma cada uno en una línea de texto y escribe el contenido completo en personas.txt.

ListaPersonas.java · guardar() 
public void guardar() {
    try {
        PrintWriter escritor = new PrintWriter(archivo);

        for (int i = 0; i < registros; i++) {
            Persona p = lista[i];
            String linea = p.getId() + ";" +
                           p.getNombre() + ";" +
                           p.getEdad();
            escritor.println(linea);
        }

        escritor.close();
    } catch (Exception e) {
        e.printStackTrace();
    }
}

Aspectos esenciales

PrintWriter permite escribir texto; println() agrega una línea por persona y close() cierra el escritor. En este ejemplo, abrir PrintWriter con la ruta del archivo reescribe el contenido anterior: no agrega automáticamente al final.

Por eso se recorre el arreglo completo: el archivo se reconstruye con todos los registros actuales. La carpeta files debe existir para que esta versión pueda crear el archivo correctamente.

07. Relación entre CRUD y persistencia

Las operaciones se realizan sobre el arreglo. Cuando cambia la información, se invoca guardar() para reflejar el cambio en el archivo.

ListaPersonas.java · registrar() 
public void registrar(Persona p) {
    p.setId(id++);
    lista[registros] = p;
    registros++;
    guardar();
}
ListaPersonas.java · actualizar() 
public void actualizar(Persona p, int id) {
    for (int i = 0; i < registros; i++) {
        if (lista[i].getId() == id) {
            lista[i].setNombre(p.getNombre());
            lista[i].setEdad(p.getEdad());
            break;
        }
    }
    guardar();
}
ListaPersonas.java · buscar() 
public Persona buscar(int id) {
    Persona p = null;
    for (int i = 0; i < registros; i++) {
        if (lista[i].getId() == id) {
            p = lista[i];
            break;
        }
    }
    return p;
}

La operación eliminar() del proyecto desplaza elementos dentro del arreglo, reduce registros y después llama a guardar(). Las consultas, como buscar() o toString(), no necesitan guardar porque no modifican los datos.

Detalle del proyecto de referencia: en eliminar(), el ciclo de desplazamiento utiliza j < registros. Si el arreglo está completamente lleno, podría intentar acceder fuera de sus límites. Este detalle no cambia el mecanismo de persistencia que se está estudiando.

08. ¿Qué ocurre al ejecutar el programa?

Main→Controlador()→ListaPersonas()→cargar()

En Main se crea el controlador y se ejecuta iniciar(). El constructor del controlador crea una instancia de ListaPersonas, cuyo constructor llama a cargar().

Main.java 
public static void main(String[] args) {
    Controlador app = new Controlador();
    app.iniciar();
}

Cuando el usuario registra una persona, la vista solicita los datos, el controlador llama a personas.registrar(p) y ListaPersonas actualiza el arreglo y guarda el archivo.

Registrar→Arreglo Persona[]→guardar()→personas.txt
